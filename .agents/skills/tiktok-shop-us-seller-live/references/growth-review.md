# 选品、增长与复盘工作模板

除注明“来源方法”的曲线分类外，以下为基于课程大纲目标新编的工作模板和测算方式，非讲师原附件或逐字稿。对应 L6、L8、L11、L14、L15、L18、L20–L23。仅有课程题目时，不推定课程中的具体方法。曲线分类另据《对外版-26-H1-TikTok Shop直播拍卖培训营》附录10-1.1，读取日期2026-10-20；不能据此声称已读取 L15 的完整授课内容。

## 商品分层与排品

先填 SKU、可售库存、售价、折扣条件、成本、履约约束和可证明卖点。按本场目的分配引流、利润、形象角色；“拍卖”另记为销售机制，允许与前三类角色重叠。缺少利润或售后数据时标为待确认，不凭售价判断利润。

| 时段/触发条件 | SKU与角色 | 展示证据/演示 | 承接商品 | 价格与库存核对 | 负责人 |
|---|---|---|---|---|---|
| 开场/待填 | 待填 | 待填 | 待填 | 待填 | 待填 |
| 核心讲解/待填 | 待填 | 待填 | 待填 | 待填 | 待填 |
| 回顾/待填 | 待填 | 待填 | 待填 | 待填 | 待填 |

时间轴随实际库存、演示时长和观众问题调整；任何稀缺、优惠和功能陈述都应有事实依据。

## 先确定数据口径

每张表记录：来源页面/导出文件、市场、币种、时区、场次起止、归因窗口、更新时间、人数或次数、去重方式、支付/取消/退款处理。平台展示值保留原名称和定义；自算值另列。

| 指标 | 记录方法 |
|---|---|
| 场观、停留 | 保存平台定义；不把进入次数当独立访客，不把平均停留与总观看时长比较 |
| 点击率、转化率 | 明确是哪一环节；商品CTR须核对点击人数/次数及对应商品曝光人数/次数的分母；分子、分母应属于同一群体和时间窗 |
| AOV、UPT | 自算 AOV=同口径GMV÷订单数；UPT=成交件数÷订单数；注明支付、取消和退款口径，不把订单当买家 |
| 每买家件数、每买家销售额 | 分别为成交件数÷去重买家数、同口径GMV÷去重买家数；与UPT、AOV分列 |
| GPM | 先取得平台定义，分母待核实；不默认是人数、观看次数或曝光次数 |
| UV价值 | 若自算，写明所选销售额÷同窗去重访客；注明币种、归因、退款口径，不冒充平台指标 |
| 退货率 | 明确退货订单数/件数/金额及对应成交基数、观察期；未走完售后周期的场次需注明 |
| 投产比 | 若自算，写明归因销售额÷对应广告支出；说明含税、退款、归因窗口；与净利润投资回报分别报告 |

无定义、缺字段或分母为零时，输出“无法计算”及缺失项。同名不同口径的数据不得直接合并、排名或比较。

拍卖另记录去重竞拍参与人数、实际成交订单、成交买家、件数、包裹数及起拍/终价倍率。订单、买家和包裹是不同对象，须分别取得；竞拍参与人数或高终价倍率不能单独证明利润。

若使用 LIVE GMV Max，先分清平台 ROI 与广告增量回报：读取时官方说明把活动运行期间直播间付费与自然流量收入均纳入整体收入指标，不能把整场 GMV÷广告费称为纯广告带来的回报。按当前归因定义、活动时段和订单数据核实；不把自然流量订单重复归因。[官方产品说明，读取于2026-10-20](https://ads.tiktok.com/resources/help/article/differences-between-live-shopping-ads-and-live-gmv-max-campaigns?lang=en)

### 拍卖利润测算（新编）

利润估算 = 商品净结算收入 + 商家实收运费 + 可归属补贴 − 商品成本 − 实际包裹物流及包装 − 尚未扣除的平台/支付费用 − 广告 − 售后及其他成本。

先核对净结算收入是否已扣平台费、退款、折扣；已扣成本不再扣，已计收入的运费和补贴不再加。费率同时记录计费基数：是否含买家运费、税、优惠前后金额及另收费用；不能仅凭“平台费 X%”推断保本价。按实际包裹计算物流，不直接按订单或买家数替代。所有参数、费率、合单和观察窗口由现有资料确定，不固定为某个案例值。缺利润或订单数据时，列出缺失项，并按用户确认的上下界给测算区间和情景；无上下界依据时用变量区间，不能捏造金额或精确单值。条件化算例须紧邻写出假设，不把假设计算值称作已确认的保本起拍价。

## 单场排查与复盘

| 观察 | 待验证假设 | 所需证据 | 下一步 |
|---|---|---|---|
| 0场观 | 未成功开播、数据延迟或触达不足 | 开播状态、直播记录、数据更新时间 | 先确认状态和统计，再评估内容触达 |
| 进入后停留短 | 首屏表达或演示与预期不符 | 对应时段录屏、进入来源、停留数据 | 只替换一个开场变量并记录 |
| 有观看少点击 | 商品展示、挂品或引导不清 | 挂品状态、商品点击、脚本时间点 | 核对链接与展示再试讲解 |
| 有点击少成交 | 价格、运费、库存、信息或下单环节存在阻力 | 商品页、可售状态、评论及订单数据 | 按证据检查具体环节 |
| 曲线异常 | 活动、切片、投放、掉线等事件关联 | 同时段事件日志和录屏 | 对齐时间，区分相关性与因果 |

复盘填写：本场目标 → 起点数据 → 实际动作及时间点 → 同口径结果 → 其他可能影响 → 下一场一项改动 → 负责人/观察窗口。优先与自身可比场次比较，不虚构平台达标线；一场上涨不能证明动作有效。

## 六种典型曝光曲线（来源方法）

来源：[《对外版-26-H1-TikTok Shop直播拍卖培训营》](https://bytedance.larkoffice.com/wiki/ImFFweVlliFt5dkwO6ucTmTvnKf)附录10-1.1。保留原形态名称，以下排查动作将原文的因果解释改为待验证假设。

先确认横轴时间桶、左右轴、曝光/观看口径及GMV是累计值还是分桶值。曝光或观看次数是流量，实时在线人数是时点存量，不能互代；识别形态时固定原始指标并分别命名。累计GMV通常不会回落至零；识别“尖刺、峰谷”应使用对应的分桶GMV序列，不能把累计曲线套进分类。

| 来源形态名 | 观察特征 | 排查或复测 |
|---|---|---|
| 健康型（标杆） | GMV与曝光/观看同频峰谷 | 对齐录屏和商品节点，记录可能可复用动作 |
| 极速流断流型 | 短时尖峰快速回落、GMV尖刺 | 查首段留存、对应回放和流量来源 |
| 有曝光无成交型 | 观看/在线稳定而GMV接近零 | 查讲品、价格、信任证据、商品卡及结算环节 |
| 开播脉冲型 | 开播大峰后长期低位 | 回看前5分钟内容，与相同时段可比场对照 |
| 持续低位平稳型 | 两线近底 | 查后台违规通知、曝光来源和技术健康；原文提到违规、IP漂移，均需另有证据 |
| 内容爆发型 | 逐渐爬升，中段出现峰值 | 对齐商品与回放节点，在后续可比场复测 |

曲线只能提示排查方向，不能据图认定限流、算法标签或IP漂移，也不能承诺修改IP能提升曝光。

## 素材与预算试验草案

素材表：素材ID、预热/切片、素材出处与使用权、主张证据、目标人群、对应商品、发布/投放窗口、直播承接动作、结果口径、保留或修改理由。比较时记录时段、商品、价格、人群等差异，避免把同时变化归因给单个素材。

预算草案填写：目标、用户给定总上限、周期、可接受试验损失、素材数量、分阶段分配、评估窗口、暂停条件、复查人。缺总额或成本数据时给参数表，不擅定金额或通用投产阈值。此处只产出草案，不执行投放，不承诺收益。

## 大促与四周迭代

大促表逐项核对：官方活动日期与时区、报名/资格、实际优惠条件、备货依据和补货时间、库存同步、运费与履约能力、售后安排、素材/场次排期、投流预算上限、负责人。活动规则与价格要求按当前官方信息核实。

四周计划可按“建立同口径基线 → 单变量试验 → 可比场次复测 → 汇总与下周期选择”组织；每周填目标、动作、证据、负责人和复查日。30天/月度看板汇总场次结果、退款成熟度及实验记录，并用“投流×内容×选品”关联具体变化，避免直接相加不同归因窗口的销售额。
