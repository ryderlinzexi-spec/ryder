# 首播准备与现场执行模板

以下为根据大纲目标新编的工作模板，非讲师附件或逐字稿原文。

适用于准备首播、补齐开播流程或排查执行问题。时间点是排期参考，可按团队调整；不代表平台要求。用真实资料填写，未知项写“待核实”。

## 1. 入驻、商品与设备盘点

场次：〔日期／目标观众时区／时长〕；目标：〔本场要验证的问题〕；主责：〔姓名〕。

| 盘点项 | 填写内容与动作 | 负责人／完成证据 |
|---|---|---|
| 店铺与账号 | 〔站点／主体／店铺状态／直播账号绑定与权限〕；在当前后台核对状态，记录缺口 | 〔人／后台截图或核查记录〕 |
| 类目与资料 | 〔品类／SKU／已有资质／材料缺项〕；依据当前官方要求核实，不从旧课表推定资格 | 〔人／官方页面与核查日期〕 |
| 商品事实 | 整理材质、规格、适用范围、使用与养护方法、已证实卖点；标出不能确认的表述 | 〔人／商品页或证明材料〕 |
| 交易信息 | 核对真实售价、可售库存、规格映射、配送承诺与售后信息，确认前后台一致 | 〔人／核对表〕 |
| 设备与场景 | 记录已有手机或电脑、摄像、收音、灯光、电源、网络及软件；试录检查画面、声音、演示空间 | 〔人／试录片段与问题清单〕 |
| 促销工具 | 若计划用券、折扣或其他工具，核实当前规则、账号资格、预算和生效条件，再填写真实利益点 | 〔人／配置截图与规则来源〕 |

先用现有条件试播，依据实测问题决定是否调整设备，不把购买器材设为前置任务。

## 2. 从 T-24h 到收播

| 阶段 | 可执行动作 | 负责人／完成证据 |
|---|---|---|
| T-24h：准备 | 确定目标观众与商品顺序；备好实物、商品事实卡、价格库存表；列出缺失资料与处理人 | 〔人／场次表与缺口表〕 |
| 开播前：联调 | 检查网络、电源、收音与光线；核对商品卡和规格；走一遍讲解、上架、问答、异常切换 | 〔人／彩排片段与修正记录〕 |
| 开播前：放行 | 再核对商品、价格、库存、促销条件及待核实表述；逐项标注“可用／暂缓／已替换” | 〔人／最终检查表〕 |
| 开场 | 清楚介绍本场内容与正在演示的商品；确认观众能听清、看清；按真实反馈调整 | 〔人／开场时间点与反馈〕 |
| 直播中 | 按商品卡讲解和演示；中控同步正确商品；记录高频问题、异常及发生时间 | 〔人／事件日志〕 |
| 收播前 | 复述已确认的购买条件与常见问题；按实际安排结束，避免虚构倒计时或库存紧张 | 〔人／收尾时间点〕 |
| 收播后 | 保存可用记录，处理未答问题与订单异常；对照目标写出证据、原因假设、下一场改动 | 〔人／复盘表与待办〕 |

## 3. 人员分工

| 角色 | 本场职责 | 交接物 |
|---|---|---|
| 主播〔人〕 | 讲解、实物演示、回答已知问题；不确定时请运营核实 | 商品事实卡、待答问题 |
| 中控〔人〕 | 商品卡切换，核对价格、规格、库存与促销展示 | 当前商品编号、异常截图 |
| 场控〔人〕 | 关注声音画面、评论和节奏；提示主播处理现场问题 | 问题队列、事件时间点 |
| 运营〔人〕 | 准备资料、确认商品信息、协调履约售后与复盘 | 核查记录、后续负责人 |

可一人兼任。兼任时缩减商品和操作数量，明确〔谁在主播演示时检查评论和商品卡〕；无人接手的任务写入待办，避免口头默认已完成。

单人单手机时，先在当前界面演练商品切卡和评论查看；采用“展示讲解 → 放稳商品 → 查评论并回答 → 核对下一张商品卡”的分时顺序，避免同时演示、读评论和切卡。无法独立完成的复杂工具暂缓，先缩小货盘完成基本流程；不自动要求增购设备或多人配置。

## 4. 商品讲解卡

商品〔名称／SKU／对应商品卡〕；目标需求〔真实使用场景〕；事实依据〔材料链接或文件〕。

1. 引入：“如果你在〔场景〕需要〔需求〕，可以看看这款〔商品〕。”
2. 展示：“这里是〔可见细节〕，我现在演示〔实际操作〕。”
3. 说明：“已确认的〔材质／规格／功能〕是〔事实〕；适用与限制是〔边界〕。”
4. 问答：常见问题〔问题→有依据的回答〕；未知问题〔记录→交给谁核实〕。
5. 购买指引：“商品卡是〔编号〕，请确认〔规格〕；当前价格和优惠条件是〔真实信息〕。”

仅在有可核实商品素材时扩展中英双语；英文与中文保持事实和限制一致。素材不足先列缺口，不补造功效、优惠、稀缺性或达人背书。

## 5. 异常处理卡

| 情况 | 现场动作 | 恢复依据与记录 |
|---|---|---|
| 掉线／音画异常 | 能沟通时如实说明；检查当前连接、收音和供电，按已彩排方案切换；恢复后复核商品卡与交易信息 | 〔人／测试结果／影响时段〕；不把重连当成故障已解决 |
| 无库存／规格缺货 | 暂停该规格推介，核对可售量并调整展示；只推荐确有库存的替代品，不承诺未知补货时间 | 〔人／库存记录／受影响商品或订单〕 |
| 冷场／少互动 | 继续清楚演示，提出与商品有关的真实问题，回答已有问题；记录是入口、内容还是操作需要验证 | 〔人／时间点／本次调整与反馈〕；不编造评论、成交或抢购气氛 |

本场复盘只留：〔发生了什么〕→〔可验证证据〕→〔原因假设〕→〔下一场改一个什么动作／负责人〕。
