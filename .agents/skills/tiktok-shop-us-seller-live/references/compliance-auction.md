# 合规审校、证据整理与拍卖准备

话术、证据及准备表为新编工作模板，非讲师附件或逐字稿。H1 拍卖正文方法见 [auction-playbook.md](auction-playbook.md)；本文件另记录读取时的官方纠错，后续应用仍核对适用市场、店铺类型和后台。

## 规则核实

涉及入驻、处罚、赠品、拍卖准入或权益恢复时，先查当前美区官方规则及适用店铺后台通知，记录来源、发布日期或生效日期、适用条件。无法核实时标注“待核实”，仍可整理现有材料。

课程所称“真人＋实时口播＋动态演示”是强调的内容要素，不构成免罚承诺。大纲提示 Giveaway 未打赠品标签可能存在判罚风险；标签是否必需、如何设置及其他限制仍需核对，不能推断打标签即合规。

## 话术审校表

先保留原句，再给出有证据支持的替换句；证据不足时删去断言或留待补充。

| 原句/时间点 | 待查问题 | 支持材料 | 修改稿/待确认项 |
|---|---|---|---|
| 待填 | 绝对化效果、医疗功效或保证结果 | 商品资料/测试报告/适用规则 | 待填 |
| 待填 | 价格、折扣、库存及截止时间不一致 | 当前商品页与活动设置 | 待填 |
| 待填 | 材质、证书、产地或品牌关系无依据 | 对应 SKU 的真实材料 | 待填 |
| 待填 | 赠品条件或站外引导表达 | 当前规则与实际活动条件 | 待填 |

珠宝脚本仅使用实际资料支持的材质、规格及证书表述；不把仿制、镀层或莫桑石写成其他材质，不扩展证书覆盖范围。

## 判罚与申诉工作底稿

先读取通知原文，避免凭商家转述判断违规原因。

| 字段 | 填写内容 |
|---|---|
| 店铺/案件 | 店铺标识、处罚编号、通知时间、影响范围 |
| 平台所述问题 | 原文、对应内容/商品/直播时间点 |
| 期限与入口 | 后台显示值及核实日期，未取得则标缺失 |
| 事实时间线 | 发生时间、具体动作、可定位的记录 |
| 证据目录 | 编号、文件名、来源、时间范围、证明事项 |
| 已有整改 | 实际完成动作、完成时间、截图或记录 |
| 请求与缺口 | 希望复核的具体事项、尚缺证据 |

草稿按“请求复核事项 → 事实与证据编号 → 对争议点的解释 → 已完成整改”组织。区分已证实事实与商家判断；证据冲突时先列出冲突。仅整理真实材料，不补造截图、交易、发票、录屏或证词。缺证据写“缺失”，不写“已附件”。健康分修复及考察期权益恢复以当前通知为准，不承诺时限或结果。生成草稿不代表已提交，也不扩大提交授权。

## 拍卖准备与争议记录

此表用于备场；H1 的“五步法”和三种上架路径另见拍卖参考文件。

| 检查项 | 待填内容/核实证据 |
|---|---|
| 准入与商品 | 店铺及账号资格、类目限制、适用规则来源 |
| 商品透明度 | SKU、实拍、状态、瑕疵、规格、材质依据 |
| 竞拍设置 | 后台实际支持的起拍价、加价、时长等设置 |
| 履约说明 | 邮费、配送范围、订单与库存核对方式 |
| 组盘与分工 | 商品顺序、演示负责人、订单核对负责人 |
| 高争议项 | 描述不一致、瑕疵未展示等问题及处理状态 |

争议发生后记录订单/场次编号、争议时间、双方陈述、商品展示片段、页面及订单记录、适用处理规则、处理进度。先核对事实再形成回复草稿；不凭课程标题推定退款责任，不承诺规则外补偿。未核实准入、商品描述或履约条件时，将相关项列为待解决事项。

## H1 拍卖课纠错与官方核对记录

读取日期：2026-10-20。以下是有日期的参考快照，不代替每次执行前的现行规则核验。课程与适用官方规则冲突时，移除冲突打法；官方范围含糊时，把相关功能列为待核实，不直接启用。

| 事项 | 使用边界与直接来源 |
| --- | --- |
| 员工“破冰首拍” | 不让卖家、主播、员工、亲友、伙伴及关联账号出价或托价；工作人员可以讲解、报系统结果和核单。[Requirements & Guidelines，2026-10-13](https://seller-us.tiktok.com/university/essay?default_language=en&knowledge_id=6110392477746958) |
| 运费作“隐形保护价” | 不用高运费补商品利润，不重复收取合单全额运费；费用透明且对应真实履约。课程中的相反建议不采用。[同一规则](https://seller-us.tiktok.com/university/essay?default_language=en&knowledge_id=6110392477746958) |
| 保留价、低价取消 | 不提供 Reserve Price（保留价）机制或“低于成本不成交”方案；公开声明也不能使其合规。内部保本测算用于开拍前决定起拍价或是否上拍。已完成竞拍按最终最高价履约，不因价格低取消、换物或重拍。[Creator T&C，2026-09-08](https://seller-us.tiktok.com/university/essay?knowledge_id=7310999191963406) |
| 临时改参数、人工延时 | 起拍价、时长与结束方式在开拍前核定；开始后不临时改动。系统延时按预设机制触发；冷场改动只用于后续尚未开始的拍品。[Requirements](https://seller-us.tiktok.com/university/essay?default_language=en&knowledge_id=6110392477746958) |
| 加价与时长 | 只用当前系统允许的参数；未核实有自设最低加价步长功能，不照抄课中 $5–$10。功能指南读取时显示 3 秒至 2 分钟，仍以当前后台和适用规则核实；讲解总时长不是倒计时时长。[功能指南，2026-10-16](https://seller-us.tiktok.com/university/essay?knowledge_id=8427133325330222) |
| 链接、实物与返场 | 一个拍卖链接对应一件明确实物。拍卖/一口价/套组分别分配真实库存，不用多个链接重复出售同一实物；已成交物不重拍。套组能否上架及格式需先核实。[Requirements](https://seller-us.tiktok.com/university/essay?default_language=en&knowledge_id=6110392477746958) |
| 置顶与展示 | 商品卡、镜头所示和讲解对象须一致；商品已置顶、展示清楚且准备好再启动倒计时。[Creator Guide](https://seller-us.tiktok.com/university/essay?knowledge_id=126960048342800) |
| 合单窗口 | 不把课中 24h 或 48–72h 写成默认。读取时官方指南区分续单免运费 3h 与优惠合单 6h；资格、仓库、地址及运输方式影响适用性。运费优惠与实际包裹合并分别核验，不靠延迟付款或超发货时限实现合单。[合单指南，2026-10-09](https://seller-us.tiktok.com/university/essay?default_language=en&knowledge_id=3802241234011918) |
| 随机商品、轮盘和盲盒 | 不把付费转盘、非官方随机工具、自封神秘首饰盒当成合法 Surprise Set。需要独立核实功能权限、允许类目、产品格式及充分展示条件；普通珠宝经营资格不等于随机玩法权限。[Best Practices & FAQs，2026-10-08](https://seller-us.tiktok.com/university/essay?knowledge_id=5425223583352594) |

### 资格与金额：按场景核实

一般拍卖、自播、达人合作、临时发品和 Surprise Set 不共用一套门槛。读取时一般竞拍资料写卖家 AHR >150、创作者 CHR >150 等要求；临时发品另有 SPS ≥3.5 等条件，不能只看一个分数就判定可用。[官方 FAQ](https://seller-us.tiktok.com/university/essay?knowledge_id=5425223583352594)

联盟合作另有卖家 SPS、AHR 和创作者要求，不将其套在所有自播场景。[Open & Target Collaboration，2026-09-22](https://seller-us.tiktok.com/university/essay?knowledge_id=5309151215666965)

课中“单件含税 $2,500 上限”未核实为当前跨境默认。美区创作者指南区分本土与国际卖家，所链接跨境说明未成功读取正文；问金额时继续核对对应市场/主体的规则和当前后台，不能泛化本土数值。[创作者指南](https://seller-us.tiktok.com/university/essay?knowledge_id=126960048342800)、[待核实跨境说明](https://seller.tiktokglobalshop.com/university/essay?identity=1&knowledge_id=6982657536952081)

课程的“48h 发货”、运费 15% 占比、赠品占比、GMV 门槛等不得当统一政策。履约期限按订单与当前适用要求；费用及促销方案按真实成本、结算展示和适用规则设计。
